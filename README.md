# POO

Repositório destinado ao estudo e à prática dos principais conceitos de Programação Orientada a Objetos (POO) utilizando Java.

# 📚 Sobre o projeto

Este repositório reúne questões e exercícios desenvolvidos durante os estudos de POO, abordando conceitos fundamentais da programação orientada a objetos.

Os exercícios têm como objetivo praticar a criação de classes, organização de código, reutilização de funcionalidades e aplicação dos principais pilares da orientação a objetos.

# 🧩 Conteúdos abordados
  ## Encapsulamento 
  
    Modificadores de acesso (private, public e protected)
    Métodos get e set
    Controle de acesso aos atributos
    
  ## Herança
    
    Classes superclasses e subclasses
    Reutilização de atributos e métodos
    Uso de extends
    Sobrescrita de métodos
    
  ## Polimorfismo
    
    Sobrescrita de métodos (@Override)
    Referências da superclasse para objetos das subclasses
    Comportamentos diferentes para um mesmo método

  ## Interfaces
    
    Criação e implementação de interfaces
    Uso de implements
    Definição de comportamentos comuns entre diferentes classes

# 🎯 Objetivo

O principal objetivo deste repositório é registrar a evolução dos estudos em Programação Orientada a Objetos, servindo como material de consulta e prática para conceitos fundamentais da linguagem Java.
